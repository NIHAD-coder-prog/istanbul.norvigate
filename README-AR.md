# بوابة إسطنبول الدولية — istanbul.norvigate.com (النسخة النهائية للرفع)

الشعار: الأصلي (الحزمة الأولى). لتبديله لاحقاً: استبدل الملفات في `public/brand/` بالأسماء نفسها ثم أعد البناء.
الفهرسة معطّلة حتى تفعّلها (`NORVIGATE_ALLOW_INDEXING=true`).

## الملفات المهمة
- `DEPLOY-AR.md` خطوات الرفع على الخادم (Docker + Caddy)
- `CONTENT-AR.md` إضافة المحتوى الحقيقي وتغيير حالات الميزات وإظهار/إخفاء ما لم يجهز
- `LAUNCH-CHECKLIST-AR.md` ما يجب أن تزوّدني به أو تفعله قبل الإطلاق العام
- `QA-REPORT-AR.md` تقرير الفحص: ما تحقق وما لم يتحقق
- `.env.example` المتغيرات

## ما في الموقع
خمس لغات (en tr ar es fr) مع RTL · الرئيسية بلمعان الشعار · الخدمات · التجارب · دليل المدينة · الأسئلة الشائعة · عن البوابة · البحث · الطيران والفنادق · الترجمة · السفر · إدراج النشاط · البوابة المميزة (تسجيل مبكر) · المتجر (قائمة، منتج، سلة، طلب شراء بلا دفع) · الأدوات (عملات، صلاة، طقس) · الرؤية والمسار · الصفحات القانونية (مسودات) · 404 حقيقية.
محتوى بملفات JSON دون بناء · مستويات ظهور (live/beta/all) ومعاينة خاصة بالمالك · نماذج بتحقق مزدوج · CSP صارمة بـ nonce.

## ما لم يُبنَ عمداً
الدفع الإلكتروني (iyzico) والمتجر الحي وأسعار الشحن: بعد تسجيل الشركة وموافقة مزوّد الدفع. المتجر الآن طلبات شراء فقط.

## أوامر
npm ci · npm run dev · npm run build && npm start (أو الحاوية)
npm test · npm run typecheck · npm run i18n:check · npm run content:check · npm run test:api (يحتاج خادماً يعمل)
npm run submissions [kind] [limit]  (عرض الطلبات المحفوظة)
